# SecureSense README image assets

These images are included so the root README.md can display the project enclosure visuals directly from GitHub.

- `securesense_sensor_node_enclosure.png` — focused crop from the SecureSense sensor-node enclosure concept.
- `securesense_sensor_node_concept.png` — full sensor-node concept board.
- `securesense_main_hub_enclosure_isometric.png` — main hub enclosure isometric render.
- `securesense_main_hub_enclosure_exploded.png` — main hub enclosure exploded/service render.
- `securesense_main_hub_enclosure_top.png` — main hub top render.
- `securesense_main_hub_enclosure_usb_side.png` — main hub USB/rear-side render.

Keep the `docs/images` directory in the same relative location when uploading the README and images to GitHub, otherwise the README image links will not render.
